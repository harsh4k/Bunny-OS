First time? Do this

  1. Click Download for Windows (or Mac) above.
  2. Open the file you downloaded. If Windows warns you, choose More info → Run anyway.
  3. When Bunny opens, tap through the short setup (microphone + optional chat engine).
  4. Hold F9 and talk. Or click the Bunny icon near your clock.

Prefer one command? Advanced users can use the install scripts on GitHub. Always read our Privacy Policy and Terms first.
