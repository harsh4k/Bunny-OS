Indian law context

This policy references the Digital Personal Data Protection Act, 2023 (DPDP), the Information Technology Act, 2000, and related rules. You install Bunny yourself. Processing stays on your PC, so Bunny is not a cloud service collecting your data on our servers.

What may be processed (locally)

  • Temporary voice audio for speech-to-text (not kept as raw files)
  • Chat / transcripts; optional Memory facts and session log
  • Installed-app names from a read-only scan
  • Settings and short-lived technical logs (~7 days)
  • Optional focused-window UI text if Screen context is On
  • Optional one GitHub Releases check if you click Compare

Your controls

Mute the mic, turn Memory / Screen off, delete facts, clear session, uninstall, and wipe app data. Grievances: GitHub Issues.

Third parties you may open

Ollama, YouTube, Spotify, browsers, and GitHub have their own policies. Bunny does not send your mic audio to them for AI.
